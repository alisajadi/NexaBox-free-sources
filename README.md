# فهرست عمومی NexaBox

این مخزن فقط منابع و پروکسی‌های عمومی رایگان را نگه می‌دارد. کد و اطلاعات
خصوصی برنامهٔ NexaBox در مخزن جداگانه و خصوصی باقی می‌مانند. هیچ پروفایل
خریداری‌شده، توکن یا اطلاعات دستگاه کاربران اینجا ارسال نمی‌شود.

لینک ثابت برنامه:
https://raw.githubusercontent.com/alisajadi/NexaBox-free-sources/main/free-connection.txt

برای اضافه‌کردن کانال یا سورس، فایل `sources.txt` را باز کنید، آیکون مداد
Edit را بزنید و در هر خط یک لینک HTTPS قرار دهید. سپس Commit changes را
بزنید. نمونه:

```text
https://t.me/s/LonUp_M
https://raw.githubusercontent.com/ALIILAPRO/v2rayNG-Config/main/sub.txt
```

فایل `free-connection.txt` خروجی خودکار است؛ آن را مستقیم ویرایش نکنید.
Actions → Refresh public connection list → Run workflow دریافت فوری را
اجرا می‌کند. زمان‌بندی هر ۳۰ دقیقه است؛ GitHub ممکن است آن را با تأخیر
اجرا کند و در مخزن کم‌فعال پس از ۶۰ روز خاموش کند. فقط کانال عمومی
خوانده می‌شود؛ کانال خصوصی/توکن پشتیبانی نمی‌شود.

GitHub لینک‌های پروکسی پست‌های اخیر کانال را بیرون از شبکهٔ دستگاه در
`channels/<name>.txt` ذخیره می‌کند. برنامه این TXT را می‌گیرد، بنابراین
برای این کانال نیازی به دسترسی مستقیم دستگاه به تلگرام نیست؛ خود GitHub
باید در دسترس باشد. سورس‌های HTTPS دیگر به‌صورت مرجع داخل فهرست قرار
می‌گیرند. هنگام خطای کانال، نسخهٔ قبلی نگه داشته می‌شود. دریافت لینک
به معنای سالم یا قابل‌اعتماد بودن پروکسی نیست؛ برنامه اتصال را جداگانه
آزمایش می‌کند.

همهٔ فایل‌ها در اینترنت عمومی‌اند. پنهان‌بودن لینک در رابط برنامه، آن
را محرمانه نمی‌کند. فایل خصوصی برای خواندن به مجوز دستگاه نیاز دارد؛
توکن صاحب مخزن نباید داخل EXE گذاشته شود. Free Connection در برنامه
قابل غیرفعال‌کردن است و پروفایل‌های شخصی مستقل‌اند.
